05 · Accessibility & bilingual

WCAG 2.2 AA, RTL day-one.

Bilingual is not "add Arabic later." It's a constraint baked into every primitive.

Focus state

Every interactive element shows a 3px orange focus ring at 25% alpha — never a generic browser outline.

Contrast
AA · 12.4:1
plum on cream
AA · 4.6:1
orange on cream
AAA · 14.1:1
cream on plum
Reduced motion

All durations collapse to 0.01ms when prefers-reduced-motion is set. Hero scroll-image becomes static. Reveals snap.

@media (prefers-reduced-motion: reduce) { … }
RTL · Arabic

الأكاديمية

اللغة العربية مدعومة منذ اليوم الأول. كل المسافات والحدود تستخدم خصائص منطقية.

Per-component checklist

  • Colour contrast ≥ 4.5:1 for text · ≥ 3:1 for UI
  • Visible focus state on every interactive element
  • Touch targets ≥ 44 × 44 on mobile
  • Semantic HTML — <button> not <div onClick>
  • Keyboard navigation works (Tab, Enter, Esc)
  • Screen-reader announcements verified in VoiceOver
  • prefers-reduced-motion respected
  • RTL layout works — mirrored padding, borders, text alignment
  • Works at 200% zoom without horizontal scroll
06 · Voice & copy

Warm. Direct. Built. Never corporate.

Sentences earn their length. We use serif italic only for emphasis, never for whole paragraphs.

Do
  • "72 hours. One brief. One trophy."
  • "Apply by Jun 12 — cohort fills early."
  • "Ship a real identity for a real client."
Don't
  • "We are excited to announce…"
  • "Solutions for synergistic creative outcomes."
  • "Click here to learn more!"
