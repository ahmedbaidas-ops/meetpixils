Walk me through how MCP servers work, and how that's different from regular tool use in the Claude API. Keep it concrete — pretend I'm shipping something next week.

Good prompt. Here's the short version, then the practical bit.

The headline difference

Tool use is a request shape — your code defines tools, sends them with a message, and runs them when Claude asks. MCP is a transport — a separate process exposes a stable set of tools (and resources, prompts) over a small protocol, and any client can plug in.

You can ship without MCP. You can't ship MCP without tool use. MCP is what tool use grows up into when you have ten clients hitting the same toolkit.

When to reach for each

  • Tool use — single app, tools change per release, the contract lives in your code.
  • MCP — multiple clients (Claude Desktop, Code, your own app) share the same tools, or you want third parties to author tools without forking your codebase.
